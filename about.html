Our mission

Field Instruments is an educational project dedicated to making precision measurement tools accessible to everyone with a browser. We believe that curious minds should not have to install specialist software or buy expensive hardware before they can explore how the physical world is measured.

The project exists to shorten the distance between a scientific idea and a hands-on experiment. A student who has read about decibels, celestial coordinates or barometric pressure can open a tab, start a measurement and watch the abstract concept become a moving chart. That immediate feedback is the point. The written guides are there to make sure the chart is interpreted rather than merely admired.

What we build

The project ships five browser instruments: a star finder, a sound level meter, a vibration analyzer, a magnetic field mapper and a barometric altimeter. Each tool turns device sensors into live, explorable measurements, and each one is designed to run entirely on the user's device. No account is required, and no measurement is uploaded.

Every instrument follows the same structure. There is a live dashboard with charts and numeric readouts, a short explanation beside the dashboard, a longer technical guide, and a clear statement of limitations. The repetition is deliberate. A reader should be able to move from a raw number to an interpretation without leaving the site.

How the tools work

Browsers expose sensors through standard web APIs. Microphone audio arrives as a stream of samples, motion sensors report acceleration and rotation, the magnetometer reports a three-axis field vector, and the geolocation API supplies latitude and longitude after permission is granted. A barometer, where the device has one, reports atmospheric pressure. The instruments read those streams, perform the relevant calculations in JavaScript and draw the result on a canvas.

Nothing in that pipeline requires a server. The catalogue of stars is a static file, the astronomical transforms run locally, the Fourier transforms run locally and the CSV export is generated in the browser. Closing the tab ends the session. That architecture is both a privacy decision and a reliability decision: once the page has loaded, the tools keep working without a network connection.

Our approach

We favour local-first design, open scientific concepts and plain-language explanations. Instrument pages pair live dashboards with written context so that a reading can be interpreted rather than merely displayed. Where a measurement has a known weakness, we say so next to the tool instead of hiding it in a footnote.

The charts are deliberately legible rather than decorative. A waveform shows time, a spectrum shows frequency, a history chart shows change and a numeric readout gives the current value. Each view answers a different question. Learning which view to trust for which question is a large part of becoming fluent with an instrument.

About the author

Field Instruments is independently designed, built and maintained by Abdul Rehman.

Abdul is a web developer who works on browser-based scientific and educational tools. He wrote the instrument interfaces and the explanatory guides, and he maintains the site, the sensor integrations and the accuracy notes that accompany each tool. The project is intentionally small and independent: there is no editorial board, no sponsored instrument reviews and no hidden commercial relationship with sensor manufacturers.

Questions, corrections and reproducible bug reports are welcome through the contact page. Corrections that improve technical accuracy are treated as a priority.

Accuracy, privacy and advertising

These are educational instruments, not certified laboratory equipment. Phone sensors vary widely, browser implementations differ and environmental conditions affect almost every measurement. Each guide explains the relevant limits, and each tool is honest about what it cannot do. Where absolute accuracy matters, the correct answer is a calibrated instrument operated by a qualified professional.

Sensor data stays on the device. The site does not create user accounts, does not store measurements on a server and does not sell personal information. Advertising, where present, is served by Google AdSense and is described in the privacy policy, including the use of cookies and the DoubleClick DART cookie. Advertising never changes the measurement or the interpretation of a reading.

Educational use: These tools are for educational and experimental purposes and should not replace professional calibration equipment.
