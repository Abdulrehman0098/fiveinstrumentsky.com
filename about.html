Our mission

Field Instruments is an educational project dedicated to making precision measurement tools accessible to everyone with a browser. We believe that curious minds should not have to install specialist software or buy expensive hardware before they can explore how the physical world is measured.

What we build

The project ships five browser instruments: a star finder, a sound level meter, a vibration analyzer, a magnetic field mapper and a barometric altimeter. Each tool turns device sensors into live, explorable measurements and each one is designed to run entirely on the user's device.

Our approach

We favour local-first design, open scientific concepts and plain language explanations. Instrument pages pair live dashboards with written context so that a reading can be interpreted rather than merely displayed.

Educational use: These tools are for educational purposes and should not replace professional calibration equipment.
