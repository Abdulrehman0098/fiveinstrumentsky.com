BUGS FIXED (what was broken → what works now)
=============================================================================

1. STAR FINDER CANVAS WAS BLANK (critical)
   → getAltAz() had double-negation: `if (!lat !== null || !lon !== null)`
     Fixed to: `if (lat === null || lon === null)`
   → drawStars() used undefined globals `rectW`/`rectH` (always 0) for
     screen projection. Fixed to use local `cssW`/`cssH` (w/dpr, h/dpr).
   → drawConstellations() same bug. Fixed.
   → Dead module-level `let rectW=0, rectH=0` globals removed.
   → drawCelestialBody() math verified: uses `w/(2*dpr)` correctly.
   → Sky background gradient now renders (createRadialGradient).
   → Compass ring (N/E/S/W + NE/SE/SW/NW) drawn.
   → Horizon line drawn.
   → Star glow for bright stars (mag < 0) via radial gradient.
   → Planet positions computed from planets.json via astronomy.js.
   → Sun + Moon markers with gold/silver glow.
   → getAltAz fallback computation included (inline JD math) if astronomy.js
     unavailable.

2. iOS PERMISSION HANDLING BROKEN
   → startOrientation() was reading bare `perm` variable (undefined in scope).
     Fixed: `const perm = starsState && starsState.perm || null;`
   → startLocation() same bug. Fixed identically.
   → WireControls status panel click handler was calling `Permissions.*`
     (module-level) instead of `perm.*` (instance). Fixed to use starsState.perm.
   → iOS 13+ DeviceOrientationEvent.requestPermission() now correctly called
     from inside the click handler (user gesture preserved).

3. TAB SWITCHING BROKEN
   → main.js called `mod.onActivate()` but modules export `activate()`.
     Fixed: `mod.activate(state, SensorBus, Utils, Permissions)`.
   → URL hash routing now works: #stars, #sound, etc. Refresh preserves tab.
   → Tab switching sets aria-selected, shows/hides panels, lazy-loads modules,
     calls destroy() on previous, activate() on new.
   → Logo click resets to STARS tab.

4. VIBRATION ANALYZER CRASHED ON START
   → Used `Utils.detectSpike()` without importing Utils. Fixed:
     `import Utils from '../utils.js'` added.

5. MAGNETIC FIELD MAPPER BUTTONS OVERWROTE SVG ICONS
   → Tone/Haptic toggle buttons called `textContent = 'Tone: On'` which
     wiped the SVG icon. Fixed: text node manipulation preserves SVG.

6. INDEX.HTML HAD TYPO
   → `id=" insecure-banner"` had leading space. Fixed: `id="insecure-banner"`.
   → Added missing `id="stars-fps"` element for FPS counter.

7. SOUND METER MISSING FEATURES
   → dB(C) readout not implemented. Added: currentDBc, sound-db-c element,
     updateDisplay reads active unit from .unit-toggle-btn.active.
   → Unit toggle UI (dB SPL / dB(A) / dB(C)) missing from HTML.
     Added: 3 toggle buttons with data-db-unit attributes.
   → Unit toggle CSS added to instruments.css.

8. NO PREMIUM GALAXY BACKGROUND
   → Flat navy background replaced with procedural galaxy:
     • Radial gradient: #0d1530 center → #05060d edges
     • 3 nebula layers: rgba(120,40,180,0.08), rgba(30,80,200,0.10),
       rgba(200,80,40,0.05) with filter: blur(120px)
     • Vignette: 60% black at edges
     • 3-layer canvas starfield (far/mid/near) with twinkle + drift +
       shooting stars every 15-30s
     • prefers-reduced-motion respected
     • Low-end device detection (hardwareConcurrency < 4) reduces density
     • Light theme: galaxy replaced with parchment #fff8ec gradient
     • Panels: rgba(10,14,26,0.72) + backdrop-filter: blur(12px)
   → Galaxy canvas (id="galaxy-starfield") placed inside main content.
   → Galaxy module imported in main.js and initialized on boot.

9. MISSING SENSOR BUS
   → main.js referenced SensorBus but no module existed. Created
     scripts/sensor-bus.js with on/emit/once event bus.

10. INSECURE CONTENT BANNER
    → HTTPS guard banner fixed (id typo + proper hidden/show logic).
